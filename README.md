# uni-timetable
Generates phone wallpapers from my university timetable in my preferred colourscheme.

## Usage
1. Copy the template file and open it in a text editor.
2. Run `generate.py` and follow the prompts. After each class, paste into the document - the correct line will have been copied to your clipboard.
3. Compile it.
4. Run `scaler.py file.pdf`
